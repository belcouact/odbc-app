1. Script templates now always list their title, applicable data, description, size and example link: when the published catalog cannot be read, the copy shipped with the app is used instead of bare file names.
2. "View" on a template opens its sample dashboard as a rendered page again instead of showing the raw HTML source; the page is served by the app (or from the local copy when present), so it also opens faster.
3. The template catalog retries sooner after a network hiccup, so a temporary connection problem no longer leaves the picker incomplete for several minutes.
4. The intro animation's feature tiles are taller, so every description fits inside its box.
5. The Alex icon in the top bar plays the Alex voxel show full-screen inside the app; close it with the button or the Escape key.
