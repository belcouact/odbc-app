1. Query grid — smarter copy: with a drill-through filter active, the Copy button now exports only the rows you can see (the drilled-down set) instead of the whole result; row selections still take priority.
2. Summary tab — sortable table: click any column header (group-by columns, Column name, or a statistic) to sort the table; clicking again flips the direction, a third click returns to the original order. Copy and Download Excel follow the sorted order.
3. Summary drill-through: clicking a row in the Summary table or pivot now scrolls the Query page smoothly to the results grid, so the drilled rows are in view as soon as you land.
4. About page: two new info cards show the technology behind the app — the frontend stack (React · MUI · AG Grid · ECharts) and the backend stack (Python · FastAPI · pyodbc · pandas).
