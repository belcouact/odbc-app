1. New "Token usage" tab under Settings → AI Assistant shows how many tokens the AI assistant uses: totals for today, the last 7 days and all time, donut charts breaking usage down by feature and by model, and a 14-day bar chart per model.
2. The tab lists recent AI calls in a table — time, feature, model, input tokens, output tokens and latency — with previous/next page buttons and a selector for how many rows to show per page (10/25/50). The table is always visible; no extra clicks needed.
3. A refresh button reloads the numbers on demand and "Reset usage" clears the locally recorded history. Usage is recorded only on this machine and monitoring never blocks AI features.
