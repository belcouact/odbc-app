1. Results grid — paste data: a new Paste button sits next to Upload, and Ctrl+V pastes straight from Excel. When the grid already holds rows the paste replaces them (Revert undoes it); a pasted header row becomes the table's column names, and empty rows are dropped.
2. Chart area — secondary Y axis: bar, stacked bar, trend, step line, area, stacked area and combo charts now offer the Y2 (secondary) shelf, so a second measure is plotted on its own right-hand axis (the top axis for horizontal bars).
3. Chart area — Visualizations pane: the chart type panel now collapses and expands sideways into a slim rail on the right, matching the Fields rail, instead of folding up and down.
4. Chart area — column types: a column type changed in the results grid is reflected in the chart builder's column panel straight away, and a saved BI snapshot keeps the types its columns had.
5. Laminate Lab Results (analyze-tautona-data): the script now opens a native Windows dialog first, listing every test component (ANALYSIS + RESULT_NAME) so unwanted ones can be unchecked; set LAMINATE_SKIP_PICKER=1 to analyze everything without the dialog.
