1. Uploading spreadsheets is much faster: .xlsx files are now read by a native parser (roughly 5× quicker) and the grid rows are serialized by pandas, so large Excel and CSV uploads reach the screen in a fraction of the time.
2. The in-app assistant now stays on topic: it helps with querying, data and statistical analysis, scripting, charts and how to use the app, and politely declines unrelated questions. It also no longer invents table or column names when it has no schema.
3. The feedback board is now a full page: it scrolls like every other view, carries its own "Feedback" title and a Close button, and the unread badge clears as soon as you close it.
4. The feedback icon in the top bar now matches the AI assistant icon — same filled glyph and app-blue colour.
5. The top bar no longer shifts on load: the version badge shows a placeholder immediately and the update status is read once the browser is idle, so the first paint stays stable and quick.
6. New feedback posts pre-fill and lock your name, while the title, description and category are required — anything missing is flagged with a warning, and toast messages are colour-coded by type (green success, yellow warning, red error).
