1. In the SQL editor's criteria section, clearing a criterion now removes the condition it had added to the SQL, instead of leaving a stale filter such as "xxx = '0'" behind.
2. The FabLIMS LSN, Lot Genealogy and Package Info queries now return rows in a stable, meaningful order — LSN by manufacture date, and the genealogy and package queries by work order lot and date.
3. New Script template: Lamination Genealogy — queries FabLIMS lot genealogy and LSN for the work order lots you list, and builds a self-contained ECharts dashboard showing the raw face/film/backer usage feeding each work order's packaged lots, with hover details.
