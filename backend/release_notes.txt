1. Scheduled tasks (new): a clock button in the top bar opens a board of timed runs. Point a task at saved SQL, an app template or one of your saved scripts and run it every few minutes, daily, weekly or monthly — then enable or pause it, run it on demand, and review its run history. Tasks fire while the app is open, and a run missed while it was closed is picked up the next time you open the app.
2. The script editor gained a Cancel button: a running script can now be aborted at any time, instead of waiting for it to finish or hit its timeout.
3. In the new-schedule dialog the name is required, the "save rows to the warehouse" option is a checkbox that starts off, and the template/script picker no longer draws its label over the value you picked.
