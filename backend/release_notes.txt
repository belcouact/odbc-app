1. Updates no longer start by themselves: checking for updates (on startup, via "Check now", or the automatic background check) now only shows the update banner and the About card. The download and install begin only when you click "Update now" — in the top banner, under Settings → About, or in the "Update required" dialog — so an update can never interrupt queries, uploads or other work in progress.
2. Removed the small reconnect button in the top-right corner of the title bar. The app reconnects to its local server automatically (it keeps probing every few seconds while offline and the moment you return to the tab), and the "Lost connection" banner at the top still offers a manual "Retry now". The red/green icon had become redundant clutter.
