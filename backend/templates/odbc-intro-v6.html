ODBC Query AppDay 0

What if anyone could just ask the database?

Day 0. An analyst has a Monday deadline and no SQL. This is how the answer got built, one small step at a time.

Day 1: just get the rows.

Start with the simplest thing that works: pick a connection, a table and a few filters. The SQL writes itself.

Maya asks for shipped revenue by region. A plain list is enough for now.

Day 3: make it visible.

Rows are hard to read. Bar, pie, trend, scatter and SPC charts turn them into a picture.

Maya: "Can I see it as a picture?" So charts came next.

Day 5: dig deeper.

Charts raised new questions, so Python and JavaScript can now run right on the grid.

Maya: "What is each region's share?" So scripts came next.

Day 8: ask for help.

Not everyone writes SQL. The assistant writes it, explains results and drafts whole sets of charts.

Maya: "Who is falling behind?" So the assistant came next.
